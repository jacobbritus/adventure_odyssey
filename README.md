# Turn-Based RPG (Python + Pygame)

A personal project where I’m building a turn-based RPG inspired by one of my favorite childhood games, *Adventure Story*.  
This project helps me practice Python, learn how to structure larger projects, and experiment with game development concepts.

---

## About the Project
This is a single-player RPG built with **Python** and **Pygame**, featuring exploration, battles, and simple RPG mechanics.  
It is still a **work in progress**, but already includes several core systems.

## Features
- ✅ Small overworld area  
- ✅ Two enemy types  
- ✅ Turn-based battles (up to 8 participants)  
- ✅ UI (menu book, status bar, battle UI)  
- ✅ Items system 
- ✅ Dialogue system
- ✅ Level system

---

## Keybinds
- `c` and `w a s d` or click to navigate the battle menu.
- `c` just before attacking to perfect block.m
- `c` just before attacking to critical hit.
- `h` to toggle hp bar.
- `m` to open menu.
---


## Installation
1. Clone the repository:  
 ```bash
 git clone https://github.com/jacobbritus/adventure_odyssey.git
 cd adventure_odyssey/
 ```
2. Install dependencies:
  ```bash
  pip install -r requirements.txt
  ```
3. Run the game:
  ```bash
  python main.py
  ```
